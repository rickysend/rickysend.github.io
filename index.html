How I work with agents

Rules over corrections

I write agent rules after watching the same mistake twice, not before. A rule that comes from a real failure is one the agent will actually follow.

Verify, then report

I check DevTools and terminal output myself, so my bug reports tell the agent what I already ruled out. That narrows the search before the agent starts.

Commit before every change

Git and checkpoints are two separate undo systems, and I use both. A bad change is reversible, which makes experimenting cheap.
